# Internship & Job Listing Portal

The Internship & Job Listing Portal is a web application that helps students and job seekers find internship and job opportunities in one place. Users can search for jobs, view details, and apply online, while admins can manage job listings and applications.

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB

## Project Structure
- `client/` - React frontend
- `server/` - Express backend and database logic
- `docs/` - Requirements and data model documents
