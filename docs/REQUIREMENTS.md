# Internship & Job Listing Portal - Requirements

## 1. Project Overview

The Internship & Job Listing Portal is a web application that helps students and job seekers find internship and job opportunities in one place. Users can search for opportunities, view job details, and apply online. Admins can manage job listings and view applications.

## 2. User Roles

- **Job Seeker:** Can view available jobs and internships, search and filter opportunities, view job details, and submit applications.
- **Admin:** Can add new job listings, edit existing listings, delete listings, and view applications submitted by users.

## 3. Functional Requirements

### Job Seeker
1. View all job and internship listings.
2. Search listings by title or company.
3. Filter listings by location and type.
4. View full details of a listing.
5. Apply to a listing by submitting a form.

### Admin
1. Add a new listing.
2. Edit an existing listing.
3. Delete a listing.
4. View applications received.

## 4. Non-Functional Requirements

- The website should work on mobile and desktop.
- The website should be easy to navigate.
- The website should load quickly and provide a smooth user experience.

## 5. Application Workflow

1. The user opens the Internship & Job Listing Portal.
2. The homepage displays available jobs and internships.
3. The user searches or filters opportunities based on their interests.
4. The user selects a job or internship to view its full details.
5. The user clicks the Apply button.
6. The user fills in the application form with the required information.
7. The user submits the application.
8. The website displays an application confirmation message.
